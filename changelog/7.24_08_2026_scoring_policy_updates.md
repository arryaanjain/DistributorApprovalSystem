# Hardening Credit Decision Engine: Eliminating Unverified Score Inflation

Fixing the scoring mechanics in `api/internal/engine/scoring.go` and `api/internal/engine/risk.go` so that form-filling alone without successful verifications cannot earn points or inflate credit ratings.

## User Review Required

> [!IMPORTANT]
> **Major Scoring Policy Changes**
> 1. **Unverified Credit Risk**: If no CIBIL report exists (`vers.CreditReport == nil`), points awarded drop from 15/30 (default neutral) to **0/30** (Unrated / Pending Verification).
> 2. **Unverified KYC & GST**: Form-filled PAN / GST inputs without verified status (`vers.PAN.Status == "verified"`) drop from 10/15 points to **0/15 points**.
> 3. **Data Integrity Default**: Data integrity score changes from defaulting to 10/10 (unverified) to requiring verified name matches (`NameMatch == true`) to earn points. Unverified applications score **0/10**.
> 4. **Self-Reported Score Cap**: Unverified applicants will score a maximum of **30/100 points** (`GRADE_HIGH_RISK`), guaranteeing they cannot be granted credit without third-party verification.

## Proposed Changes

### Credit Engine

#### [MODIFY] [scoring.go](file:///home/arryaanjain/Desktop/Everything/DistributorApprovalSystem/api/internal/engine/scoring.go)
- **`credit_risk` (30 pts max)**:
  - Remove neutral default 15 pts. Require active `BureauScore`. If `vers.CreditReport == nil`, award **0 pts**.
- **`identity_kyc` (15 pts max)**:
  - Require `vers.PAN.Status == "verified"`. If unverified, award **0 pts** (remove the 10 pts fallback for unverified string presence).
- **`business_verification` (15 pts max)**:
  - Require `vers.GST.Status == "verified"`. If unverified, award **0 pts** (remove the 10 pts fallback for unverified string presence).
- **`data_integrity` (10 pts max)**:
  - Start at **0 pts**. Award 5 pts if PAN name matched (`vers.PAN.NameMatch == true`) and 5 pts if GST name matched (`vers.GST.NameMatch == true`). Unverified applications receive 0 pts.
- **Re-balancing Weightages**:
  - **70% Core Verified**: CIBIL (30) + PAN (15) + GST (15) + Data Integrity (10).
  - **30% Secondary Business Data**: Vintage (10) + FMCG Exp (10) + Capacity (5) + Brands (5).
