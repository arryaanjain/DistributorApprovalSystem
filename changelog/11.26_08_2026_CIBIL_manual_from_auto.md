# Implementation Plan - Manual CIBIL Report & Score Calculation

Transition the CIBIL credit report retrieval and score calculation process from an automatic background task triggered upon distributor onboarding completion to a manual action initiated by admins via the Admin Dashboard.

## Proposed Changes

### Backend (`api/`)

#### [MODIFY] [service.go](file:///home/arryaanjain/Desktop/Everything/DistributorApprovalSystem/api/internal/service/onboarding/service.go)
- Remove the asynchronous `go func` in `SubmitConsent` that automatically invokes `verSvc.TriggerAll` (fetching CIBIL) and `creditSvc.EvaluateApplication` (calculating score).
- Keep real-time PAN and GST instant verifications in `SubmitStatutory` intact for input validation, but defer full CIBIL report fetching and scoring to manual admin action.

---

### Admin Frontend (`admin/`)

#### [MODIFY] [Applications.tsx](file:///home/arryaanjain/Desktop/Everything/DistributorApprovalSystem/admin/src/views/Applications.tsx)
- Update the application review drawer to feature explicit, dedicated manual buttons for:
  1. **Fetch CIBIL Report**: Triggers CIBIL bureau fetch via Surepass.
  2. **Calculate Credit Score**: Runs score computation engine and decision rules.
  3. **Fetch CIBIL & Calculate Score**: Combined quick-action button in the header and verification panel.
- Update CIBIL credit score status cards and badges to indicate "Pending Manual Run" when not yet calculated.
- Provide clear status feedback upon manually triggering CIBIL fetch and score calculation.

## Verification Plan

### Manual Verification
1. **Distributor Onboarding Test**: Complete step submissions as a distributor up to consent. Verify in the database / admin dashboard that CIBIL report fetch and score calculation do NOT execute automatically upon consent submission.
2. **Admin Dashboard Test**: Open the application in `admin/src/views/Applications.tsx`.
   - Verify that CIBIL report shows "Pending Manual Run" and Credit Score shows "Not Calculated".
   - Click "Fetch CIBIL Report" / "Calculate Credit Score" manually and confirm that CIBIL report is retrieved and score is computed successfully.
   - Verify PDF download link appears after manual CIBIL report fetch.
