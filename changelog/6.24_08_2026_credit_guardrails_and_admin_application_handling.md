# Implementation Plan — Onboarding Status 404, Admin Completion Status & Dynamic Credit Guardrails

Resolve the 404 error on `/api/v1/onboarding/status` for approved distributors, update Admin status displays to show "Completed", and replace hardcoded credit limit placeholders in `Step9Dashboard.tsx` with dynamic, guarded credit offer limits.

## User Review Required

> [!IMPORTANT]
> **Key Behavior Changes**:
> 1. `GET /api/v1/onboarding/status` will return the distributor's latest application state (including `offer_generated`, `credit_active`, `advance_only`, `trial`, `approved`) instead of throwing a `404 Not Found`.
> 2. `Step9Dashboard.tsx` will no longer display a static hardcoded `"₹ 500,000"` credit limit placeholder. It will display the actual sanctioned credit line (`assigned_credit_limit`) or `"Advance / COD"` if no credit line is active.
> 3. `Applications.tsx` and `Dashboard.tsx` in the Admin app will display the application status badge as **Completed** once the credit decision/offer is generated.
