# Implementation Plan - CIBIL API Token Cost & Reliability Hardening

Eliminate wasteful, repeated Surepass CIBIL API calls (~₹200/call), prevent double-token consumption per fetch (JSON + PDF), enforce strict pre-flight data validation, and improve error feedback in the Admin Dashboard.

## User Review Required

> [!IMPORTANT]
> **Token Cost Saving Key Changes:**
> 1. **Single Token Fetching**: CIBIL report JSON (`/fetch-report`) will be fetched on demand. The PDF endpoint (`/fetch-report-pdf`) will NO LONGER be called automatically during score computation, cutting token consumption by 50% per fetch.
> 2. **Pre-flight Validation & Fallbacks**: Before calling Surepass CIBIL API, the backend will strictly validate `PAN` (10-char pattern), `Mobile` (10-digit phone), and `Name` (resolving fallback from Verified PAN Holder Name -> GST Legal Name -> Business Profile -> Account Name). If pre-flight validation fails, the API call is aborted before any paid token is consumed.
> 3. **Caching & Failed Attempt Tracking**: Failed CIBIL requests or no-history responses will be cached and tracked in `credit_reports` table so system retries will NOT repeatedly drain tokens unless `force=true` is explicitly requested by an admin.

## Verification Plan

### Manual Verification
1. **Pre-flight Validation Test**: Attempt to fetch CIBIL for an application missing a valid PAN or phone number. Verify that the backend returns a 400 Validation Error and 0 requests/tokens are sent to Surepass.
2. **Single Token Verification**: Execute "Fetch CIBIL Report" for a fresh applicant with valid PAN/mobile. Verify in server logs that only 1 single HTTP POST (`/credit-report-cibil/fetch-report`) is made to Surepass.
3. **Caching & Guard Test**: Click "Fetch CIBIL Report" a second time without `force`. Verify that existing cached credit report is returned without making an HTTP request to Surepass.
4. **Score Calculation Test**: Click "Calculate Credit Score". Verify that credit scoring engine evaluates the cached CIBIL score without triggering a Surepass API call.
