# Implementation Plan - Production-Grade Shiprocket Logistics Integration

Replace the basic Shiprocket stub with a full multi-step shipping management pipeline in the Go backend and React Admin dashboard, drawing reference from the PHP implementation (`ShiprocketService.php`, `ShippingController.php`, `ShiprocketWebhookController.php`) and React component (`OrderManager.tsx`).

## Proposed Architecture & Workflow

```
┌──────────────────────────────────────────────────────────────────────────────────────────┐
│                                ADMIN LOGISTICS WORKFLOW                                  │
├──────────────────────────────────────────────────────────────────────────────────────────┤
│ 1. Create Shipment Modal      │ Input package weight, L x B x H, pickup location, method │
│ 2. Fetch Serviceability       │ Retrieve live couriers, ETD & rates from Shiprocket API │
│ 3. Pre-Flight Wallet Guard   │ Check wallet balance vs selected courier rate           │
│ 4. Assign Courier & AWB       │ Generate AWB & assign courier company                   │
│ 5. Auto Request Pickup        │ Schedule courier pickup                                  │
│ 6. Print Label & Manifest     │ Generate printable Label PDF & Manifest PDF              │
│ 7. Webhook Status Tracking    │ Real-time delivery status updates from Shiprocket        │
└──────────────────────────────────────────────────────────────────────────────────────────┘
```
