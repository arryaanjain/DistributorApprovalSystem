# Distributor Onboarding & Commerce Pipeline Enhancement

Complete the distributor portal's end-to-end commerce and onboarding flow across 5 workstreams: admin application tracking, dynamic credit metrics, sample kit Razorpay flow, admin order segmentation, and Shiprocket logistics integration.

## User Review Required

> [!IMPORTANT]
> **Razorpay Integration**: The current sample order flow generates *fake* `rzp_order_` IDs instead of calling the real Razorpay Orders API. This plan proposes integrating the [razorpay-go](https://github.com/razorpay/razorpay-go) SDK to create **real** Razorpay orders server-side, and loading Razorpay Checkout.js on the frontend. This requires valid `RAZORPAY_KEY_ID` and `RAZORPAY_KEY_SECRET` in `.env`. **Is the test-mode Razorpay keypair already configured?**

> [!IMPORTANT]
> **Shiprocket Credentials**: The Shiprocket integration requires email/password credentials. You mentioned env variables but they aren't in `.env.example` yet. **Do you want Shiprocket integration wired to sample orders (auto-ship on payment), commercial orders (admin-triggered), or both?**

> [!WARNING]
> **Address Collection for Sample Kits**: The current sample flow doesn't collect a shipping address. The plan adds an address form within the sample booking modal (before payment). This address will be stored alongside the sample order for Shiprocket shipping. **Is this acceptable, or should the address from Step 1 business details be reused?**

## Open Questions

1. **Sample Kit Pricing**: Currently defaults to ₹500 if no price is set. Should sample kit pricing be driven entirely by the product's `price_paise` in the catalogue, or is there a fixed override?
2. **Order Dashboard Scope**: The admin `/orders/all` endpoint is currently a stub. Should the toggle show **all** orders (including dispatched/completed), or only actionable ones?
3. **Shiprocket Auto-Ship**: Should sample orders be auto-shipped via Shiprocket upon payment verification, or should they appear in the admin Orders dashboard for manual dispatch?
